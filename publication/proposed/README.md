# Review copies, not active repository metadata

The files in this directory are candidates awaiting the owner's decision in [LICENSING_PROPOSAL.md](../LICENSING_PROPOSAL.md). Their presence does not activate a project reuse license or confirm sole authorship. `MIT.txt` preserves the standard text with the proposed holder name; its project scope is the proposed notice, not this staging directory's location.

`CITATION.cff` uses JSON syntax, which is valid YAML 1.2, for a small dependency-free metadata check. It intentionally omits license, release date, version, DOI, contact address, affiliation and ORCID. Its author list still needs owner confirmation. Do not publish it as a root citation file until that confirmation is recorded.

GitHub's [citation documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files) explains root placement and the citation display. The [CFF 1.2.0 schema guide](https://github.com/citation-file-format/citation-file-format/blob/1.2.0/schema-guide.md) defines the fields. A future paper can be cited once it actually exists; none is invented here.
