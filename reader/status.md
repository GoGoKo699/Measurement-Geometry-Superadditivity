## Current stage

The scientific model, proof, inputs, approved figures and independent numerical checks were consolidated into baseline v1 and imported into this dedicated repository at commit `9a1e4cb3bad843db9cec1fa348870ca7162df0e0`. The work now is the project website and reader experience. **Manuscript drafting remains the final stage.**

The current site is a review build. It is not publicly deployed. Repository privacy, permissions and licensing are unchanged. The website builder has no deployment command and its workflow has no Pages write permission.

## Scientific assurance

The current claim has author-side analytical and computer-assisted support. The recorded final audit found no invalidating defect within its declared scope, and its bounded prior-work comparison supports the stated working distinction. This is not external peer review, proof-assistant formalization, or exhaustive priority certification. Website checks test presentation and source preservation, not the truth of a new theorem. [Canonical status and nonclaims](../docs/MODEL_AND_CLAIMS.md#m07)

## What is preserved

The canonical proof/model, frozen argument, scientific source, numerical inputs, evidence, and all 27 approved graphical artifacts remain unchanged. The website's Gachet-inspired color versions are generated derivatives for visual review, not replacements for the approved paper exports. Their data, paths, labels, geometry and line styles are preserved. [Visual design and comparison](visual-design.md)

## What is not part of this project

The original monitored many-body entanglement study has its own repository. Its trajectory data and figures are not dependencies or evidence for this channel theorem. Neither that repository nor My-tone is modified by this work.

No new noise model, quantum-capacity formula, decoder, simulation campaign, figure panel, fitted slope, or literature-priority assertion is introduced by furnishing the reader site.

## Before public deployment

A public-site decision and a reuse-license decision must be made explicitly. The present artifact can be inspected locally, with no external scripts, analytics, web fonts, or content requests. GitHub Pages access is a separate concern from source-repository visibility. [GitHub's access-control documentation](https://docs.github.com/en/enterprise-cloud@latest/pages/getting-started-with-github-pages/changing-the-visibility-of-your-github-pages-site)
