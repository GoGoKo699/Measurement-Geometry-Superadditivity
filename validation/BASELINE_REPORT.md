## 4. What “clean directory” means here

The execution used a copy of this baseline at a different filesystem location and newly created output directories, with the recorded pinned packages already installed. No parent archive was extracted by the active code. Source integrity was checked before and after execution.

This does **not** assert that dependencies were freshly downloaded, or that every operating system and rendering-library version will emit identical figure bytes. The approved outputs are included. In the recorded environment, a redraw is required to match their hashes; a mismatch fails rather than silently replacing approved artwork. The renderer uses fonts provided with the pinned Matplotlib environment, and no standalone font files are distributed.

`verify.py` by itself checks integrity, provenance, links and independent-code boundaries. It is not the complete entropy-inequality computation. The command scopes are distinguished in `docs/REPRODUCTION.md`.
